# FieldCraft–NGSolve bridge

## Project language

Use US English (en-US) for every project example and file you create or edit.
Use US English in file and directory names, code identifiers, comments, user-facing
messages, documentation, CAD and solver examples, plot labels, tests, generated
reports, and release material. When renaming a file or a named model entity,
update and verify its references. Preserve published reference data, scientific
symbols, quoted titles, and identifiers required by an external format or API.
Conversation with the maintainer may be in German.
